Tech: Zdjęcia i nagrania

Jak myśli zapisują i wczytują zdjęcia oraz nagrania głosowe. Dokument opisuje rzeczy zaimplementowane.

Mechanizm

  • Media w bazie, przy myśli — zdjęcie i nagranie jako dane binarne.
  • Metadane obok bajtów — rozmiar zdjęcia, długość nagrania. To one, nie same bajty, mówią, czy myśl „ma zdjęcie / ma nagranie”.

Zapis

  • Zdjęcie — kompresowane przed zapisem:
    • najpierw korekta orientacji wg EXIF
    • skalowanie do rozsądnego maksimum
    • zapis jako JPEG
  • Nagranie — bez kompresji. Plik audio trafia do bazy w oryginalnej postaci; rozmiar ogranicza pośrednio limit długości nagrania.

Wczytywanie

Wspólna zasada: leniwie, na żądanie.

  • Listy i szczegóły pobierają tylko metadane — wystarczą, by pokazać ikonę / miniaturkę, bez ciężkich danych.
  • Bajty osobno, gdy trzeba je pokazać lub odtworzyć:
    • zdjęcie — dekodowane do miniaturki (podgląd) lub pełnego rozmiaru (po kliknięciu)
    • nagranie — zapisywane chwilowo do pliku tymczasowego, z którego gra odtwarzacz

Pułapki — nie ruszać

  • Widoki listy i podglądu nigdy nie ładują media razem z myślą. Media zawsze osobno, per pojedynczy rekord, w momencie faktycznego wyświetlenia lub odtworzenia.
